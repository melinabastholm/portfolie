Copenhagen Unfolded

Copenhagen Unfolded is a website design concept showcasing the city's attractions, food, and culture. The design combines a consistent visual identity with clear navigation and responsive layouts to create an engaging experience for visitors.

Figma - Existing Brand Style Guide

Assignment

The project focused on designing a website about Copenhagen using an existing brand style guide, provided text, and images. The goal was to create a visually cohesive and user-friendly design while maintaining the established visual identity across desktop and mobile layouts.

Digital design · Semester 2 · Individual project (Exercise)

Focus Points

  • UI Design
  • Visual Hierarchy
  • Responsive Design
  • Layout & Composition

Target Audience

  • Target Audience: Tourists and visitors exploring Copenhagen.
  • Interests: Local attractions, architecture, food, and culture.
  • User Needs: Easy access to information and travel inspiration.
  • Design Focus: Clear navigation, readability, and mobile-friendly layouts.
