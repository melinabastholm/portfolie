Feed the Animals

Feed the Animals is an interactive game designed around simple choices, where players learn which foods belong to different animals through playful challenges.

Tools

Assignment

The project focused on creating a cohesive game universe by combining visual identity, digital graphics, and browser-based presentation. The main objective was to explore how environments, characters, and user experience work together to create an engaging game. Visual design choices were made to support the game's genre, target audience, and overall atmosphere.

Interactive game · Semester 1 · Group project

  • Web Development
  • Digital Illustration
  • Visual Identity

Target Audience

  • Target Audience: Children aged 4–6 (pre-readers and early readers).
  • User Needs: Simple navigation, short gameplay sequences, and a safe, engaging experience.
  • Visual Style: Soft shapes, bright colours, and friendly characters.
  • UI Design: Large buttons, clear icons, and easy-to-understand interactions.
  • Atmosphere: Playful, welcoming, and calming.
